# Kátia Moreno Buffet — Landing Page

Site-modelo de prospecção para a **Kátia Moreno Buffet** (@katiamoreno.buffet), casamento completo em Salvador/BA e Lauro de Freitas.

**No ar:** https://teteuziin.github.io/site-katia-moreno-buffet/

## Sobre a página

- Hero com foto real de cerimônia pé na areia (Imbassaí) e contadores (30 anos, +2.000 casamentos)
- Pacote real dela: casamento completo por R$ 30.000 para até 100 convidados, com checklist do que inclui
- Galeria de casamentos reais com lightbox + 3 vídeos dela (inclui o feedback de um casal de noivos)
- Formulário de orçamento que monta a mensagem e abre no WhatsApp dela
- Cursor customizado, botões magnéticos, parallax e animações de scroll
- Responsivo de 360px a 1920px, sem overflow horizontal
